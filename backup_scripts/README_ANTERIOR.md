# Divergent forest-cover trajectories in the Cachoeira River basin (1985–2022)

Reproducibility package for the research article submitted to **Regional Environmental Change** (Springer Nature).

**Authors:** Ernesto Santana dos Reis and Marciel Elio Rodrigues.  
**Study region:** Cachoeira River basin, southern Bahia, Brazil.  
**Period:** 1985–2022 inclusive (**38 annual observations**, 37 year-to-year intervals).  
**Source:** MapBiomas Collection 8, annual land-use and land-cover percentages aggregated by basin and forest formation.

## Scope of reproducibility

- Four **original analytical source workbooks** (XLSX) used in the study, reproduced without numerical changes in `data/raw/`.
- Complete published analytical workflow (`scripts/01_reproduce_article.R`): OLS; Newey–West HAC p-values; Durbin–Watson; conventional Mann–Kendall; Sen slopes; annual change; standardized PCA; loadings; TIFF/PDF/EPS Figures **3–5**; quantitative Tables **1–2**.
- Automated comparison (`scripts/02_validate_against_article.R`) with the archived numeric tables in `reference/`.
- Original thesis time-series script in `archive/`, preserved unchanged; original article v5 script also archived for provenance.
- Final submitted image copies in `figures/published/`.

**Important limitations:** The four XLSX files contain **aggregated percentage time series**, not raw satellite imagery or individual raster classifications. They are the exact inputs to the statistical analyses; they are **not sufficient to regenerate the geographic maps (Figures 1–2)**, which would require basin/formation boundaries, land-use rasters, and cartographic layout/GIS layers. Figures 1–2 are included as archived publication graphics, not claimed to be regenerated by the scripts here. The submitted Figure 1 includes an editorial legend replacement. Numeric results can be reproduced from the four XLSX files with the R script; perfect pixel-for-pixel agreement in rendered figures requires identical fonts, R, package and graphics-device versions.

## Requirements

- R **4.4.3** (version reported in the manuscript; verify the actual R version used on your computer)
- RStudio recommended
- Internet on first run for package installation (`readxl`, `dplyr`, `tidyr`, `purrr`, `janitor`, `lmtest`, `sandwich`, `Kendall`, `trend`, `ggplot2`, `patchwork`, `ggrepel`, `openxlsx`, `scales`, `viridisLite`, `grid`, `stringr`)
- Windows: Arial installed and Cairo PDF/EPS support where available; TIFF output does not require Cairo.

## Quick start

1. Download or clone this repository.
2. Open `REEC_Cachoeira_Forest_Trajectories.Rproj` in RStudio, or set the R working directory to the repository root.
3. Run:

```r
source("scripts/01_reproduce_article.R", encoding = "UTF-8")
source("scripts/02_validate_against_article.R", encoding = "UTF-8")
```

From Windows PowerShell after changing into the project root:

```powershell
Rscript scripts/01_reproduce_article.R
Rscript scripts/02_validate_against_article.R
```

If PowerShell cannot locate `Rscript`, run both `source()` commands inside RStudio or use the full path to `Rscript.exe`.

The script writes `outputs/Table1_Trend_REEC.csv`, `outputs/Table2_PCA_REEC.csv`, `outputs/REEC_Tables_PCA_Loadings.xlsx`, and `outputs/Fig3_...`, `Fig4_...`, `Fig5_...` in TIFF and PDF. `outputs/sessionInfo.txt` records the working R environment. The validation exits with an error if the computed values differ from the manuscript's numeric references beyond their reporting-rounding precision.

## Key analytic choices

1. Forest cover is the column `Floresta`, in percentage points (0–100).
2. OLS models `forest ~ year`. HAC p-values use `sandwich::NeweyWest()` with `prewhite=FALSE`, `adjust=TRUE`, and lag `max(1, floor(4*(n/100)^(2/9)))` (n=38, lag=3).
3. Durbin–Watson is reported for the OLS residuals. `Kendall::MannKendall()` is **conventional** and **not corrected** for serial correlation; its p-values must be interpreted cautiously. Sen slope uses `trend::sens.slope()`.
4. Annual percentage change is `100*(forest_t - forest_(t-1))/forest_(t-1)`, starting in 1986. It is not a percentage-point change.
5. PCA uses all nonconstant numeric class proportions after removing year and the duplicate `forest` column, with column-wise z-score standardization and `prcomp()`. It includes the original `NA` class **if it varies through time**, as in the submitted analytical run. PCA component signs are oriented by the early/late PC1 ordering solely for display.
6. PCA cumulative explained variance is calculated from unrounded values and only then rounded in publication tables.

### Classification sensitivity: `NA` column

The source sheets contain a class named `NA`. In the original v5 published PCA, its varying values were treated as a numeric explanatory class for DOF, SSF and DSF. If `NA` represents unclassified land-cover pixels rather than a meaningful LULC class, there is a methodological case for excluding it. `scripts/03_optional_pca_sensitivity_NA.R` prints the variance results with and without that class. **This sensitivity check is not the published model and must not overwrite the archived article outputs without updating the manuscript.** See `docs/METHODOLOGICAL_NOTE_NA.md`.

## Files

- `scripts/01_reproduce_article.R`: full REEC article calculations and Fig. 3–5 generation.
- `scripts/02_validate_against_article.R`: verifies Tables 1–2 and confirms Fig. 3–5 outputs exist.
- `scripts/03_optional_pca_sensitivity_NA.R`: optional alternative PCA, excluding the `NA` category.
- `archive/Original_Tese_Testes_estatisticos_serie_temporal.R`: untouched source script from the thesis.
- `archive/Cap2_REEC_Figures_v5_FINAL_original.R`: untouched final original script used during article preparation.
- `reference/`: journal-reported numeric results for tolerance-based testing.
- `figures/published/`: submitted figures (Fig. 1–2 cartography included as supplied outputs).
- `data/SHA256_sources.csv`: source data checksums.

## Citation and provenance

MapBiomas Collection 8 should be cited according to the dataset citation in the article. This repository records the transformation from the four aggregated workbooks into the analytical output tables and Figures 3–5. Geospatial extraction from original MapBiomas rasters is outside its reproducibility scope until source geospatial files and GIS processing scripts are added.
