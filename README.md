# Cachoeira River basin — forest-cover time series (1985–2022)

R scripts and annual land-use/land-cover percentage tables used to calculate long-term forest-cover trends and standardized principal component analyses (PCA) for the Cachoeira River basin and three Atlantic Forest formations in southern Bahia, Brazil.

**Authors:** Ernesto Santana dos Reis; Marciel Elio Rodrigues.  
**Data source:** MapBiomas Collection 8; aggregated annual land-use and land-cover percentages for 1985–2022.

## Data

The four original analytical spreadsheets, preserved without changes, are located in `data/raw/`:

- `Bacia_percentual.xlsx` — entire basin
- `fod_percentual.xlsx` — Dense Ombrophilous Forest (DOF)
- `fes_percentual.xlsx` — Semideciduous Seasonal Forest (SSF)
- `fed_percentual.xlsx` — Deciduous Seasonal Forest (DSF)

Each spreadsheet contains 38 annual observations. These data are **aggregated percentages**, not the original satellite images, MapBiomas rasters, or vector boundaries. `data/SHA256_sources.csv` records file hashes.

## Analysis

From the repository root, in R/RStudio:

```r
source("scripts/01_reproduce_article.R", encoding = "UTF-8")
source("scripts/02_validate_against_article.R", encoding = "UTF-8")
```

The first script installs missing R package dependencies and calculates OLS linear trends, Newey–West HAC p-values, the Durbin–Watson statistic, the conventional Mann–Kendall test, Sen's slope, annual forest-cover change, and PCA of standardized land-use proportions. The second script checks the calculated results against the numeric values in `reference/` using tolerances appropriate to the reported precision.

The first execution requires access to CRAN if any dependency is not installed. Output tables, PCA loadings, Figures 3–5 and session information are written to `outputs/`.

## Treatment of the source category `NA`

`NA` is the **name of a numerical category in the source spreadsheets**. According to the data preparation used in this study, it groups other/unspecified uses; it is not equivalent to a missing value (`NA`) in R. Some low-proportion classes (e.g., mangrove, apicum, silviculture) are also supplied in **their own columns** and are not automatically merged into the `NA` column by these R scripts.

The standardized PCA uses **all numeric land-use/land-cover columns with nonzero temporal variance**, including the `NA` category where applicable. Therefore, classes not emphasized in the text can still contribute to the multivariate analysis. Variables with zero variance are omitted because they cannot be standardized. The four labeled loading vectors in Figure 5 are selected by their magnitudes in PC1–PC2 space. The original classification was not modified in this package.

The conventional Mann–Kendall p-values are not adjusted for serial correlation; Newey–West HAC inference applies to the linear regressions only.

## Repository structure

```text
data/raw/             original analytical XLSX files
data/SHA256_sources.csv
scripts/01_reproduce_article.R
scripts/02_validate_against_article.R
reference/            archived numeric results
outputs/              generated by R; excluded from version control
figures/published/    copies of the five reported figures
archive/              original thesis time-series script
```

Figures 1 and 2 are archived outputs. Their cartographic reconstruction requires source rasters/vector layers and additional map-generation procedures not included in these four aggregate tables. Figures 3–5 are generated by `scripts/01_reproduce_article.R`.
